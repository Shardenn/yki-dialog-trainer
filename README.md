# YKI Dialog Trainer

Practice the speaking part ("Dialoger") of the Finnish YKI test in Swedish, intermediate level (nivå 3–4).

Open the app: https://shardenn.github.io/yki-dialog-trainer/

- You read the situation and your instructions (30 s), then the partner's lines are read aloud.
- After each line you get a timed answer window (adjustable 5–60 s); your answers can be recorded.
- At the end the whole dialog is revealed with model answers.

All 58 dialogs are built into `index.html`. To add more, add entries to the `BANK.push(...)` list.
